## Shared contracts and acceptance corrections

- Injected clocks and ledger calculations use epoch milliseconds; wire timestamps (`scannedAt`, `modifiedAt`, `excitationAt`, `changedAt`) use ISO strings, matching the parent payload examples. Frame `dt` and transition durations use seconds. Physics takes explicit time; no model reads a wall clock implicitly when a time is supplied.
- Sources retain `kind`, `name`, `live`, `dispose()` and cancellation. Browser sources retain `getFile(path,{signal})`, returning the original or current local `File`; the server viewer uses the existing bounded preview and streaming media endpoints. Add `readSpace({signal})`, `readPlanet(id,{signal})`, `search(q)`, `tours()`. Snapshot sources remain non-live. Shared coordinator code lives in `public/universe-reader.js`.
- Atom `id` is canonical root-relative file identity; atom `path` is body-relative. The viewer adapter passes `path: atom.id` and `size: atom.atomicMass`. `mappedAtoms()` adapts to the existing file-access callback's `{files:[{path:id,...}]}` shape.
- Real repository IDs normally equal their relative paths. Paths equal to `__belt__`/`__overflow__`, or beginning with `~`, are prefixed with another `~`; actual filesystem paths remain separate. This escapes synthetic IDs injectively. Root id `.` remains valid.
- The browser-safe root endpoint is `/api/planet?id=.`. Normal path endpoints and raw literal root-dot requests remain supported, but clients do not depend on a dot path segment that URL parsing removes.
- Discovery checks Git marker names without opening their data. Flat file snapshots may not expose empty/omitted markers; report that limitation and keep such data traversable as a belt. Repositories below discovery depth remain belt molecules, rather than disappearing. Ordinary hidden-file access remains excluded; bounded `.space/tours` JSON is a narrow metadata exception.
- Metadata surveys and Git enrichment have distinct readiness. One shared Git deadline bounds a repository operation; slow Git yields snapshot fallback. Body indexes survive idle payload eviction, but are invalidated on deletion, ownership change, source disposal and obsolete survey generations. Overflow uses a bounded aggregate survey with honest partial totals.
- Builders are `buildSpaceWorld(payload,now,previousPositions?)` and `buildPlanetWorld(payload,spaceWorld,now)`. Fields expose `kind`, `potential`, conservative `acceleration`, grid-consistent `curvature`, `damping`, `sampleGrid`, and separate `buffet(position,simulationTime)` where applicable.
- Use chord-based angular spacing and collision checks in layouts. Preserve prior placements where footprints remain valid; repack deterministically where changed footprints require it. First root-file placement faces the landing approach, with a safe target fallback for bodies without root files.
- Use a continuous force-shifted dispersion cutoff and finite continuation inside contact; conservative derivative tests exclude contact/clamp boundaries and buffeting. Empty/pending/all-zero masses have finite inert constants. Calibration tests use isolated rest-mass fixtures, fixed geometry for mass rescaling, and timestep-converged thrust measurements.
- A landing finishes only when payload readiness and animation duration are both satisfied. The transition clock continues while controls and integration are disabled. Source and layer generations guard requests. Lost-body ascent uses cached geometry or a safe launch fallback. Automatic route thrust can release capture hold to finish approaching.
- Compare space/surface mass and excitation at a common revision and evaluation time. Rendering can retain transient cooling remnants, but they do not remain eligible file targets or count as live represented matter.
- Light color uses positive luminosity contributions, including individually sub-threshold atoms, so an aggregate emitter always has a defined color. Root molecules do not duplicate surface point-light selection. Each active layer has at most eight body/molecule point lights plus the ship headlamp.
- Mission goals are five available atoms and up to three available bodies; small worlds remain completable. Tours visit/land explicitly where required, retain manual-action pause across layer changes, and may include a system leg prefix plus up to seven body onboarding stops. Tours do not claim to be the separate action-gated tutorial from #19.
- Product branding remains Space Drift. `window.__SPACE__` and `window.__SPACE_DRIFT__` expose the same read-only diagnostics object for compatibility.
- Document that Git can read local working-tree data internally for dirty diffs, while the app does not add a direct physics text reader. No file contents enter world payloads or hosted uploads.

### Data acceptance audit — 2026-09-08

Audited #9 section 12, #20 and #12 against the implemented sources. The final audit run passed **125 tests**; the focused discovery/source/Git/universe/metadata suite passed **39 tests**.

- **Discovery and readiness:** filesystem and browser fixtures cover directory/file Git markers, nested-repo stopping, constellations, hidden/generated exclusions, both root rules, reserved-ID escaping, depth-cutoff matter retained in the belt, path-ordered overflow and absent empty remainder. A temporary 50-repository fixture (25 direct, 25 inside a grouping folder, including file markers) returned 51 pending bodies in **8.3 ms** and completed all metadata surveys in **29.2 ms** in the full-suite run. Git was disabled for this metadata-readiness measurement; it is not a real-workspace or Git-history performance guarantee.
- **Scheduling and identity:** injected counters/clocks verify bounded survey/Git concurrency, promotion of an already queued landing request, the background pass deadline, five-second freshness, 15-second Git caching, retained no-scan indexes after idle payload eviction, 60-result search, and rejection of obsolete ownership generations. Incomplete discovery retains unobserved known bodies until a complete walk proves their removal.
- **Matter and cooling:** represented bytes and excitation add through descendant molecules and agree across payloads at common timestamps. Caps produce partial totals and lower-bound omission flags. Deletion immediately removes an atom from mass, excitation, search and file eligibility; recreation starts a new observation. Cooling ghosts belong only to rendering. Browser handles cannot prove inode-based moves, so their fallback reports observable creation/deletion; Node snapshots carry verified moves.
- **Git:** parser fixtures cover NUL/quoted/rename/binary rows, exact HEAD line counts, statuses and chronological rename-history carry. A real temporary linked worktree used a backing Git directory outside the selected root: HEAD had 3 lines, its dirty edit had delta 3, enrichment succeeded, and replacing the marker with a missing gitdir returned `unavailable`. The fixture alone runs Git initialization/commit/worktree commands. Production commands remain read-only, suppress optional locks, fsmonitor hooks, signatures, external diff and textconv, clear inherited repository selectors, and share deadlines. Version fingerprints prevent a Git-observed edit receiving a duplicate provisional snapshot excitation. Tests cover eight nested readers, root-belt filtering and independent Git failure fallback.
- **Metadata and access:** `.space/tours` and package entry hints are explicit exceptions to metadata-only scans. Both runtimes bound metadata to 128 KiB/file, 1 MiB total, 32 tour attempts, 64 JSON names/256 directory entries per listing and a 10-second request budget. Node checks root/components, regular-file type and descriptor identity, rejects symlinks/FIFOs, uses nonblocking/no-follow opens, and closes late handles. Tests verify oversized/listing limits and literal safe package tokens. World payloads never contain file contents; canonical query/root-dot routes and surveyed-only file opening retain the existing access guards.
- **Declared limitations:** Git line denominators describe tracked HEAD text; binary/untracked/browser lines use byte estimates. Git internally reads working-tree bytes for dirty diffs. Snapshot sources cannot expose empty folders or omitted `.git` markers, remain non-live, and use a playable belt when markers are unavailable. Complete overflow totals and complete discovery are not claimed after any cap. The 50-repository timing above supplements, rather than replaces, browser and real-workspace integration verification.
